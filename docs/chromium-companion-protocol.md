# Bastle Chromium companion protocol v1

The optional companion is a separate Flatpak and trust domain. Bastle talks to
the session-bus name `io.github.cheviiot.bastle_chromium`, object
`/io/github/cheviiot/bastle_chromium/Engine1`, interface
`io.github.cheviiot.bastle_chromium.Engine1`. The only permanent permission
added to Bastle is `--talk-name=io.github.cheviiot.bastle_chromium`.

## Authentication and profile ownership

The companion accepts calls only from the Flatpak security label
`io.github.cheviiot.bastle`. A 256-bit random capability token is generated by
Bastle for each app ID. The companion binds an app ID to the first valid token
it sees and requires an exact token match for later calls. Tokens are never
included in `.bastle-backup` archives.

Each app ID owns a separate Electron `userData` directory and persistent
partition. Switching engines does not copy or remove either engine's profile.
Profile deletion failures are retained by Bastle and retried when a compatible
companion next becomes available.

## Methods

```xml
<node>
  <interface name="io.github.cheviiot.bastle_chromium.Engine1">
    <method name="GetCapabilities">
      <arg name="protocol_version" type="u" direction="out"/>
      <arg name="features" type="as" direction="out"/>
    </method>
    <method name="OpenApp">
      <arg name="id" type="s" direction="in"/>
      <arg name="url" type="s" direction="in"/>
      <arg name="title" type="s" direction="in"/>
      <arg name="width" type="i" direction="in"/>
      <arg name="height" type="i" direction="in"/>
      <arg name="maximized" type="b" direction="in"/>
      <arg name="start_in_background" type="b" direction="in"/>
      <arg name="token" type="s" direction="in"/>
      <arg name="policy_json" type="s" direction="in"/>
    </method>
    <method name="DeleteProfile">
      <arg name="id" type="s" direction="in"/>
      <arg name="token" type="s" direction="in"/>
    </method>
  </interface>
</node>
```

Protocol v1 features are `open-app`, `policy-v2`, `profile-delete`,
`permissions`, `navigation-allowlist`, `proxy`, `background`, `downloads`, and
`oauth-popups`. Bastle rejects a different protocol version and does not
silently fall back to WebKitGTK.

`policy_json` is a validated `AppPolicyV2` document with WebKit-only content
filter lists removed. Unknown fields and permission kinds are denied by the
companion rather than granted. A companion error is shown to the user with an
explicit one-time WebKitGTK fallback.
